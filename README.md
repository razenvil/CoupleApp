# ❤️ «Мы Вместе» — Приложение и Telegram Mini App для пар

> **Современное приватное веб-приложение и Telegram Mini App для двоих в премиальном дизайне Apple iOS (Human Interface Guidelines).**

Готово для бесплатного деплоя на **Vercel** и подключения базы данных **Supabase** (PostgreSQL + бесплатное защищенное хранилище файлов 1 ГБ).

Подробная инструкция по настройке бота и запуску: **[DEPLOY_GUIDE.md](./DEPLOY_GUIDE.md)**.

---

## 🌟 Основные возможности

### 1. 🛡️ Сейф документов (Documents Vault)
- **Умные карточки для билетов и документов**: шаблоны для паспорта РФ, загранпаспорта, СНИЛС, водительских прав и билетов Сапсан/Авиа.
- **Быстрое копирование в 1 клик (Quick Copy)**: удобные кнопки напротив каждого поля (ФИО, серия и номер, дата рождения) — чтобы мгновенно заполнять данные при покупке билетов на Aviasales, РЖД или Купибилет.
- **Двухфакторная защита**:
  - Экран безопасности с PIN-кодом (по умолчанию `1234`) и биометрией FaceID.
  - Маскирование номеров по умолчанию (с возможностью открыть глазок).
  - Скан-копии и PDF-файлы билетов с защищенным скачиванием.

### 2. 🎁 Хотелки (Wishlist) с бесплатным автопарсингом
- **Встроенный бесплатный парсер ссылок (`/api/parse-link`)**:
  - **Wildberries**: автоматическое извлечение артикула и прямой запрос к официальному каталогу WB — моментально достает фото в высоком разрешении, точное название и цену со скидкой. Без капч, без платных сервисов.
  - **Ozon и другие сайты**: серверный сбор OpenGraph-тегов (`og:title`, `og:image`, `og:price:amount`, JSON-LD).
- **Секретная механика бронирования подарков**:
  - Когда партнер смотрит список желаний второй половинки, он видит кнопку **«Я подарю это! 🎁»**.
  - Создатель желания **НЕ видит**, что подарок забронирован (сюрприз сохраняется на 100%!).
  - Тот, кто дарит, видит статус «Вы дарите!» и кнопку «Подарено! 🎉».
- **Архив «Исполненные мечты»**:
  - При вручении подарок переносится в памятную историю с датами и заметками под залп праздничного конфетти.

### 3. 🛒 Задачи и Списки покупок (Apple Reminders Style)
- Единый чистый список дел без громоздких разделов.
- **Мегазадачи (списки покупок)**: вложенные пункты (томаты, пармезан, базилик), которые можно вычеркивать в супермаркете в реальном времени с тактильным откликом Taptic Engine.
- Назначение ответственного: аватарки «Для меня», «Партнеру» или «Вместе».

### 4. 🎛️ Хаб «Пара» и Инструменты для двоих
- 🪙 **«Монетка судьбы»**: реалистичная 3D-монета на Framer Motion с Memoji двоих для справедливого разрешения мелких бытовых споров с Taptic вибрацией и салютом конфетти.
- 📏 **«Карточка размеров»**: памятка размеров обуви, колец, одежды и белья с кнопками копирования в 1 клик для заказа подарков без неловких вопросов.
- 💳 **«Общий кошелек скидочных карт»**: карты магазинов (ВкусВилл, Золотое Яблоко, Перекресток и др.) с открытием штрих-кода сверху вниз почти на весь экран в стиле OZON для моментального считывания сканером на кассе.
- 💌 **«Пригласить партнера»**: персональная ссылка с кодом пары для быстрого добавления второй половинки.

### 5. 🤖 Telegram-бот, вход по номеру и Push-уведомления
- **Безопасная авторизация по номеру телефона (Telegram Contact Sharing)**:
  - При первом входе бот предлагает подтвердить свой номер телефона (`request_contact`).
  - Проверка подлинности контакта исключает передачу чужих данных.
- **Мгновенные уведомления партнеру**:
  - Когда один партнер добавляет задачу, второму в Telegram приходит сообщение:  
    *«📋 [Имя] добавил(а) новую задачу: [Название]»* с кнопкой открыть приложение.
  - Также отправляются пуши при выполнении задач, добавлении хотелок и документов.

## 🚀 Быстрый запуск локально

1. Убедитесь, что установлен **Node.js 18+**:
```bash
node -v
```

2. Запустите сервер разработки:
```bash
npm run dev
```

3. Откройте в браузере:
```
http://localhost:3000
```
