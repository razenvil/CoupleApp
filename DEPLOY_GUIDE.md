# 🚀 Полное руководство по настройке Telegram-бота и деплою на Vercel

Это пошаговое руководство поможет развернуть приложение **«Мы Вместе»** в продакшен, подключить Telegram-бота, настроить безопасную авторизацию по номеру телефона и мгновенные уведомления для вашей пары.

---

## 📋 Шаг 1: Создание бота в Telegram (@BotFather)

1. Откройте официального бота **[@BotFather](https://t.me/BotFather)** в Telegram.
2. Отправьте команду:
   ```
   /newbot
   ```
3. Введите название вашего бота (например: `Мы Вместе | Наша пара`).
4. Введите юзернейм бота (должен заканчиваться на `bot`, например: `my_couple_love_bot`).
5. **Сохраните полученный HTTP API токен** (он выглядит как `7123456789:AAFlkjw9e...`). Это ваш `TELEGRAM_BOT_TOKEN`.

---

## 🌐 Шаг 2: Бесплатный деплой на Vercel

1. Загрузите проект в ваш репозиторий на **GitHub** (репозиторий может быть приватным).
2. Перейдите на сайт **[vercel.com](https://vercel.com)** и войдите через GitHub.
3. Нажмите кнопку **Add New...** -> **Project**.
4. Выберите ваш репозиторий и нажмите **Import**. Next.js определится автоматически.
5. В блоке **Environment Variables** добавьте две переменные:
   - `TELEGRAM_BOT_TOKEN`: токен, полученный от `@BotFather` на Шаге 1.
   - `NEXT_PUBLIC_APP_URL`: адрес вашего сайта (например, `https://my-couple-app.vercel.app`).
6. Нажмите кнопку **Deploy**. Через 1–2 минуты проект скомпилируется и будет доступен онлайн.

---

## 🔗 Шаг 3: Настройка Webhook для бота (1 команда)

Чтобы бот моментально реагировал на команды пользователей и запрос номера телефона, нужно привязать к нему адрес вашего приложения на Vercel:

Откройте терминал или браузер и выполните следующий запрос (замените `<ВАШ_ТОКЕН>` и `<ВАШ_ДОМЕН_НА_VERCEL>`):

```bash
curl "https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook?url=https://<ВАШ_ДОМЕН_НА_VERCEL>/api/telegram/webhook"
```

В ответ Telegram вернет:
```json
{"ok": true, "result": true, "description": "Webhook was set"}
```
*Всё, бот теперь подключен к вашему серверу!*

---

## 📱 Шаг 4: Настройка Telegram Mini App кнопки

Чтобы в чате с ботом внизу всегда была удобная кнопка **«Меню / Открыть приложение»**:

1. Откройте **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду:
   ```
   /setmenubutton
   ```
3. Выберите вашего бота.
4. Введите URL вашего приложения на Vercel:
   ```
   https://<ВАШ_ДОМЕН_НА_VERCEL>
   ```
5. Введите текст для кнопки: `Мы Вместе`.

*(Опционально: можно также создать приложение через команду `/newapp`, чтобы открывать его по ссылке вида `t.me/your_bot/app`).*

## 🔒 Как работает безопасная авторизация по номеру телефона

Во избежание подмен аккаунтов реализована официальная двухфакторная механика Telegram Contact Sharing:
1. Когда партнер впервые нажимает `/start`, бот приветствует его и отправляет защищенную клавиатуру с кнопкой **`📱 Подтвердить номер телефона`**.
2. Пользователь нажимает кнопку — Telegram запрашивает подтверждение отправки номера.
3. Telegram передает контактный объект от своих защищенных серверов.
4. **Защита от подделки (Anti-Spoofing)**:
   - Сервер сверяет: `contact.user_id === message.from.id`.
   - Если кто-то попытается отправить чужую визитку или контакт друга, сервер заблокирует вход и потребует свой номер.
5. После подтверждения номера бот фиксирует авторизацию и выдает персональную кнопку **«📱 Открыть «Мы Вместе»»**.

## 🔔 Как работают уведомления для пары

Приложение автоматически уведомляет вторую половинку о важных событиях:
- 📋 **Новая задача**: когда один партнер добавляет задачу или чек-лист покупок, второму в Telegram приходит сообщение:
  > 📋 **Мария** добавила новую задачу:  
  > «**Купить сыр, пасту и вино**»
- ✅ **Выполнение задачи**: когда задача вычеркнута, партнер получает:
  > ✅ **Алекс** выполнил задачу:  
  > «**Забрать посылку из СДЭК**» 🎉
- 🎁 **Новая хотелка**:
  > 🎁 **Мария** добавила новую хотелку:  
  > «**Умная колонка**» ✨
- 🛡️ **Документ в Сейфе**:
  > 🛡️ **Алекс** сохранил новый документ:  
  > «**Билеты на Сапсан**»

Под каждым уведомлением прикреплена кнопка прямого перехода в приложение.
